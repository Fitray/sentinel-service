# Sentinel Imagery Service

Веб-сервис для автоматизированного получения спутниковых снимков Sentinel-2 через Google Earth Engine.

Проект позволяет получать спутниковые изображения по названию города и временному интервалу, автоматически выбирать наиболее качественный снимок с минимальной облачностью и экспортировать результат в форматах PNG и GeoTIFF.

## Возможности

- Регистрация и авторизация пользователей
- JWT-аутентификация
- Получение спутниковых снимков Sentinel-2
- Автоматический выбор сцены с минимальной облачностью
- Поддержка пользовательских спектральных комбинаций
- Экспорт изображений в PNG и GeoTIFF
- Хранение истории запросов
- Просмотр и удаление сохранённых запросов
- Контейнеризация с использованием Docker

## Источник спутниковых данных

Для получения изображений используется коллекция:

`COPERNICUS/S2_SR_HARMONIZED`

Особенности:

- данные Sentinel-2 уровня Surface Reflectance;
- 13 спектральных каналов;
- пространственное разрешение от 10 до 60 метров;
- возможность формирования пользовательских комбинаций каналов.

---

## Алгоритм выбора снимка

После получения запроса система:

1. Определяет область интереса по названию города.
2. Получает коллекцию снимков Sentinel-2 за указанный период.
3. Анализирует слой Scene Classification Layer (SCL).
4. Формирует маску облачности.
5. Выбирает снимок с минимальным количеством облачных пикселей.
6. Выполняет экспорт изображения в выбранном формате.

Используемые классы SCL:

| Код | Описание |
|------|-----------|
| 3 | Cloud Shadow |
| 8 | Medium Probability Cloud |
| 9 | High Probability Cloud |
| 10 | Thin Cirrus |
| 11 | Snow / Ice |

## Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/project-name.git
```

### 2. Создание файла окружения

Создайте файл `.env` и заполните необходимые параметры, который можно узнать в `.env.example`

### 3. Настройка Google Earth Engine

Необходимо:

- создать проект в Google Cloud;
- включить Earth Engine API;
- выполнить аутентификацию Earth Engine;
- указать идентификатор проекта в Python-модуле.

---

### 4. Запуск через Docker Compose

```bash
docker compose up --build
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:8080
```
